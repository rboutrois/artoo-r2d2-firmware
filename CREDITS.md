# Credits & attribution

## Steve Wagg — original creator

The **Artoo R2-D2 controller board** and the **hoverboard wheel mod** for the feet
were created by **Steve Wagg**, a member of the R2-D2 builders community. All credit
for the original hardware design and concept goes to him.

## Why this repository exists

Steve's original firmware was distributed as a binary only, was never open-sourced,
and Steve is no longer active in the community. His firmware did not fit my needs, so
I rebuilt a firmware for his board from scratch.

The functional behaviour was reconstructed by observing the original system: RC channel
mapping, web UI screenshots, public Facebook posts, and analysis of the shipped binary.
The source code in this repository is an **independent, clean reimplementation**.
Steve's original binary is **not** included or redistributed here, and the board's
hardware design remains his.

## Intent

This project is a community continuation, shared openly so that other owners of an
Artoo board are not left with an unmaintained binary.

I reached out to Steve before publishing and did not receive a reply. If Steve, or any
rights holder, would like this repository taken down or made private, please contact me
and I will comply.
